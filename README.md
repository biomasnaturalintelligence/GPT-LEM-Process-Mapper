GPT/LEM Knowledge Hub

A self-contained web toolkit for learning and applying Johanna Seibt's General Process Theory (GPT) and Leveled Mereology (LEM) to real territorial, ecological, and social situations.

Built by Biomas Foundation as part of its process-based approach to territorial analysis and regenerative land stewardship.


What's inside

The hub is a single index.html file with three paths:

Path 1 — Learn GPT/LEM

An interactive 8-step guide that takes you from zero to mapping real situations. Includes:

Conceptual introduction to process ontology

The five process types (T1–T5) with interactive cards

Classification quizzes with feedback

The five GPT parameters (automerity, participants, composition, shape, context)

LEM levels (N1–N4+) with expandable accordion

A fully worked example (coastal fishing village)

Quick-reference glossary


Path 2 — Use the Claude Skill

Instructions for installing and using the /gpt-lem-process-mapper skill in Claude Cowork mode (desktop app). Includes a direct download link for the SKILL.md file and step-by-step installation guide.


Path 3 — Real Example
A complete GPT/LEM process map generated by the Claude skill for Piracanga Ecovillage (southern Bahia, Brazil) — 150 residents, 7 years of groundwater stewardship. Shows the full output format: process cards, LEM level diagram, systemic tensions, and key leverage points.

How to use

Option A — Open locally

Download or clone the repository, then open index.html directly in any modern browser. No server required.

Option B — GitHub Pages

Fork or clone this repository

Go to Settings → Pages

Set source to the main branch, root folder

Your hub will be live at https://<your-username>.github.io/<repo-name>/


Installing the Claude skill
The /gpt-lem-process-mapper skill runs inside Claude Cowork mode (desktop app, macOS).

Download gpt-lem-process-mapper/SKILL.md from this repository
On your computer, create the folder:

~/Library/Application Support/Claude/plugins/skills/gpt-lem-process-mapper/

Place SKILL.md inside that folder
Restart the Claude desktop app
Open Cowork mode — the skill is now active

Once installed, describe any territory, ecosystem, or community situation and Claude will automatically map the underlying processes using GPT/LEM. You can also invoke it explicitly:

Map the processes in this territory using GPT/LEM: [your observations here]


About the framework
General Process Theory (GPT) is a philosophical framework developed by Johanna Seibt (Aarhus University) that provides a formal vocabulary for describing the world in terms of processes rather than objects. It classifies processes into five types based on their mereological properties (automerity and homomerity).

Leveled Mereology (LEM) organizes processes into nested levels where part-whole relations hold within levels but are non-transitive across levels — formally capturing the phenomenon of emergence.

Together, GPT/LEM enables rigorous process mapping for ecological, social, and territorial analysis: identifying what is happening, at what scales, how processes are coupled, and where leverage points lie.

Primary reference: Seibt, J. (2018). Process Philosophy. Stanford Encyclopedia of Philosophy.
